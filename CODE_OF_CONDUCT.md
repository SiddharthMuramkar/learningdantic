# Code of conduct

This project adopts the
[Contributor Covenant, version 2.1](https://www.contributor-covenant.org/version/2/1/code_of_conduct/).

In short: be kind, be patient, and assume good intent. This is a course for beginners, so every question is a
fair question.

## Where it applies

Issues, pull requests, discussions and comments on this repository.

## How to report a problem

Pick whichever feels easier. There is no email address; both ways stay inside GitHub.

- **Private report:** open this repo's **Security** tab (GitHub may call it "Security and quality"), click
  **Report a vulnerability**, start the title with `conduct:`, and describe what happened. Write n/a in any
  box that doesn't fit. Only the maintainer can see it.
- **GitHub's "Report content":** click the `...` menu on the comment, issue or pull request, then
  **Report content** ([how it works](https://docs.github.com/en/communities/maintaining-your-safety-on-github/reporting-abuse-or-spam)).
  If you see **Report to repository admins**, it comes to the maintainer; otherwise it goes to GitHub's own
  safety team.

The maintainer, [@SiddharthMuramkar](https://github.com/SiddharthMuramkar), reads every report sent to him,
keeps the reporter's identity private, and acts on it using the Covenant's enforcement guidelines.
